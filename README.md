# Component Prompt Planner

A small browser-based internal tool for turning pasted requirements and a React component/data-flow map into a reusable implementation prompt.

## Run locally

```bash
npm install
npm run dev
```

Open the URL printed by Vite. Drafts are saved automatically in the browser's local storage.

## Build a static site

```bash
npm run build
npm run preview
```

The production files are written to `dist/` and can be hosted on any static web server.
